Use your Codex desktop in real time on your phone — bidirectional sync · zero app install

简体中文 English 日本語 Deutsch
What it is: Mobile Codex (codename 8214) is a local thin web shell that reuses your desktop ChatGPT.app's codex-cli and ~/.codex data, giving your phone/browser bidirectional real-time sync with desktop (per-token reasoning & output, identical sends). Not a standalone app, no host injection, no host modification.

② Prerequisites (all systems)

  1. Install the desktop host ChatGPT.app (required) — 8214 reuses its codex-cli and data. No host, no data source.
  2. Install Node.js ≥ 18 — the 8214 backend runtime. Homebrew on macOS.
  3. Log in to the host once — sign in on desktop ChatGPT.app; 8214 shares the same credentials (no separate key storage).

③ Three-step installation

  1. Clone the code
    git clone https://github.com/ricky8848/codex-web
cd codex-web
  2. Install dependencies
    npm install
  3. Start the 8214 backend + phone tunnel
    node src/server/main.js            # 8214 listens on 127.0.0.1:8214
# Phone needs public access: stand up a tunnel to 8214 (e.g. Cloudflare Tunnel)
# open the tunnel URL in the phone browser
After install, open your tunnel URL in the phone browser → you see a Codex UI identical to desktop (chats / reasoning / command approval / images / files).

Verify installation

curl http://127.0.0.1:8214/health
✓ HTML returned = backend OK
curl http://127.0.0.1:8216/health
✓ Hub sync middleware OK
